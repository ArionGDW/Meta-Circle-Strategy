# 事件推广方案制作Skill

## 从什么开始

用用户最新确认的口径定本次事件、受众、对外披露范围、发布窗口、终审人和交付形式。优先检查聊天附件、工作区、现有方案和品牌资料。原始材料遇到登录限制时，说明具体缺口，请用户提供可读导出件，同时推进受众、渠道和排期。已有结论以最近确认的版本为准。

从原始材料提炼一条值得传播的主发现、一张能支撑它的图或演示、一个受众能回答或参与的问题。研究成果对外使用数字时，保留任务、基线、指标和关键条件。将同条件的对照与包含额外优化的结果分开表述。涉及复现、部署、发布状态或合作承诺时，区分已有证据和待核实事项。对外素材优先用确认可用的原图或干净导出件。

## 按内容、渠道和结果制定方案

1. **内容。** 给受众一个能理解和参与的入口，再让其找到完整证据。主内容可用官网文章、研究报告或活动页承载，配套短视频、图卡、演示、问答或征集按实际事件选择。需要解释后续研究时，写已确认的场景和下一步，未定的部分标为待确认。
2. **渠道。** 先列用户点名的自有渠道，再列外部合作伙伴与备选。每个主渠道写清受众、语言、形式、交付和预期动作。合作伙伴的任务写到具体产出，例如编辑访谈、技术沙龙、定向分发。涉及不同语言的首发时，统一事实与时间窗口，文案按各平台改写。给定自有渠道首发时，外部合作按确认档期排期，是否依赖媒体同步由用户决定。
3. **结果。** 先突出用户指定的核心指标，补充指标降低视觉层级。跨平台保留原有统计口径，重叠的分享和转发避免重复加总。线索按人或机构去重并记录来源，区分名单、主动联系与实质交流。根据活动目标定义优先跟进的线索。有历史基线时可设置相对目标，没有基线时将建议值与承诺区分开。
4. **排期。** 以已确认的日期、时间和时区倒排。按需要列口径确认、合作对接、初稿、物料制作、联调、终审、发布、取数、线索跟进和复盘。执行表写责任人或交付对象，管理层概览只保留关键动作。复盘依据实际问题写下一轮动作，例如转发偏低时测试标题或开场、点击多而有效联系少时检查入口和邀请语。方案中的对接、发送与发布动作属于计划项，执行权限按当前请求另行判断。

## 交付与修改

用户要两页简报时，可以用第一页三栏「内容 → 渠道 → 预期结果」，用箭头或对齐的层级显示因果顺序。把重点平台、合作方与首要指标放在一眼能扫到的位置。第二页用时间线呈现阶段和里程碑。时间线位置、日期范围、每天详略和是否展示负责人按用户指示调整。详细执行口径可以放备注或单独执行表，按交付范围选择。

用户给出官方品牌要求时，从现有品牌资料核对色值与用法。修改现有稿时，先识别用户最新使用的版本和手动改动，再在适用的演示文稿工作流中编辑。核对页数、标题、重点顺序、品牌配色、日期与时区、合作分工和备注是否同步，渲染逐页检查后交付。

需要参考两页发布方案的制作与修改过程时，读取[两页成果发布方案示例](references/two-slide-launch-example.md)。示例中的结构和渠道分工按当前事件调整。
