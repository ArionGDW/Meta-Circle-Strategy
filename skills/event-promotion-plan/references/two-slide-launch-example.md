# 两页成果发布方案示例

以下为匿名化流程示例。用于演示怎样把原始研究材料整理为管理层可审阅的发布方案。

## 先提炼成果与参与入口

从原始材料里找出一个主发现、一张支持它的图或演示，以及一个同行能参与的问题。数字旁写清任务、基线、指标和比较条件。将同条件实验与叠加额外优化的结果分别说明。

官网报告承载完整证据。短视频或图卡先提出问题，再解释结果。需要征集后续方向时，让读者描述具体任务和实验难点，研究团队据此筛选下一轮实验。

## 第一页的三栏关系

用三栏呈现「研究成果 → 渠道 → 预期结果」，以对齐的层级和箭头显示发布如何带来互动与交流。

- 研究成果突出主发现和证据，报告、视频、图卡、征集等形式按事件选择。
- 渠道先展示用户确认的官方平台，再展示媒体和其他合作伙伴。平台名称应先于次要分类进入视线。每个合作方写清具体交付，例如技术访谈、研究视频分发或技术沙龙。
- 预期结果突出用户指定的核心指标。优先跟进的线索可包括具体研究问题、实验复现、拓展实验与合作机会，按本次目标调整。

采用品牌资料中确认的主色和辅助色。主色组织层级，辅助色强调核心指标和发布节点。

## 第二页的时间线

在用户指定的位置放关键时间线，按发布窗口倒排方向确认、合作对接、报告初稿、物料制作、发布联调、终审、上线和首轮复盘。管理层简报中每个节点保留一至两个关键动作，交付对象和详细统计口径可以放备注。

发布后按约定时点记录各平台数据与去重线索，结合评论内容和交流进度评估结果。下一次发布的优化应对应实际反馈，例如调整开场、简化交流入口或增加有效来源渠道的投入。

## 修改时检查

1. 标题与第一页的主结论是否对应。
2. 各栏第一眼看到的内容是否符合用户的优先顺序。
3. 合作伙伴的任务是否更新到最新确认版本。
4. 发布时间是否在标题、副标题、时间线和备注中一致。
5. 两页是否按要求保留可编辑内容，渲染后文字和图层是否清晰。
