# 论文完整翻译

目标：交付可精读、可批注、可追溯原文的完整中文阅读包。默认英译中；用户本次指定的范围、语言、格式和位置优先。

## 确定原文与交付位置

- 接收本地 PDF、附件、论文链接、题名或资料索引中的序号。先检查用户已给的文件与当前工作目录，沿用已有编号和命名，避免重复下载或新建同一论文。
- 优先使用用户提供的版本；未指定版本时，选可获取的正式出版版或作者官方版本，记录作者、标题、版本、日期、原文链接和来源文件。不同版本的正文、附录与图表不得混用。
- 先确认拿到全文，再开始完整翻译。链接打不开时尝试官方 HTML、PDF、出版页或作者来源。仅取得摘要时，说明具体缺失，继续整理已获得的材料，不能将摘要扩写成全文。
- 在用户指定目录或当前工作区建立“序号＋论文标题”文件夹。已有序号直接沿用；新论文不随意占用资料库编号。已有阅读包先保留译稿、批注备份和稳定段落 ID，再更新。

## 建立原文覆盖清单

先读取 [references/reading-package.md](references/reading-package.md)，据其中的数据与阅读器要求组织生产和检查。

对原文建立结构化单元，保留自然段、章节、来源位置与稳定 ID。PDF 先处理双栏顺序、页眉页脚、断词和跨页段落；扫描页采用 OCR 并抽查原图。使用官方 HTML 时，保留章节锚点，不把单元序号冒充 PDF 页码。

完整范围包含：

- 题名、作者及版本信息、摘要、全部章节和子章节、结论、脚注、致谢、伦理或局限性说明，以及随所选全文版本提供的附录。
- 全部表格的标题、表头、逐行内容、注释和数值；全部图形及图注、图例、坐标轴与图中文字。
- 算法、提示词、例题、案例和必要补充说明。保持其原有排列和相互引用。
- 全部参考文献：保留作者、年份、出版信息、链接与标识符，逐条翻译论文题名。不扩展为翻译被引用的论文。

单独发布、尚未取得的补充材料列为缺项，不能以“已含全部附录”覆盖。保留原图，在图旁另列可选取、可批注的图中文字对照；图像模糊时标记具体未辨认文字，不编造标签。

## 逐段翻译

- 严格使用“一段英文 → 紧接一段中文”的纵向对照。保留原文自然段；长段落需要拆分时，在意义边界同时拆分英文和中文。跨页句子合并，不按版面行逐行翻译。
- 翻译范围内的内容逐项译出，不以概述代替、不跳过密集段落、表格或附录。英文来自实际原文，不能由中文反向生成。
- 中文准确、自然，保留限定语、否定、因果关系、比较对象、实验设置和作者的证据强度。作者提出的愿景、推测和实验结果分别呈现。
- 核心术语首次出现给出中文与英文，后续译法一致；模型名、数据集名与标识符保持可检索。不同论文的定义有差异时，按本篇定义处理。
- 公式、变量、代码、路径和可执行命令保持原样；翻译其说明与自然语言内容。提示词给出原文和译文，保留原有分隔、变量与占位符。
- 原文编号错误、措辞歧义或图文矛盾保留原貌，在相邻位置添加“译者注”，说明判断依据；不悄悄改写为译者认为正确的内容。
- 译者解释、教学例子和研究判断放在译者注或导读中，与作者原文清楚区分。

## 单独制作快速阅读与教程式导读

在完整翻译之外，提供独立可打开的“快速阅读.html / .md”，分为摘要、序言（Introduction）和导读三个部分。摘要与序言直接复用已核对的完整逐段译文；导读链接到独立的全文导读。用户另要总结时，加入原文结论的对照翻译。

导读服务于理解和判断，不能只是逐章复述或术语列表：

- 从论文回答的问题和直观例子入手，解释核心机制、关键术语及论证路径。
- 尽量用一个连贯例子说明机制；明确哪些是教学假设，哪些来自论文实验。
- 指明关键公式、图表怎样读，主要结果在什么任务、基线和预算下成立，以及会改变结论的局限。
- 安排与论文难度匹配的自测问题，要求读者解释、比较或作判断；提供默认折叠的提示与核对思路，留出可保存的回答区。
- 引导读者回到相应章节或对照单元。与前文比较时，仅使用实际读过的材料，不强行套用本篇没有采用的分类或等级。

导读长度与问题数量按论文复杂度确定。可选阅读路线与扩展材料应帮助理解本篇，不自动变为公司分析、社媒稿或后续研究任务。

## 默认交付

```text
序号 论文标题/
├── 开始阅读.md
├── 逐段对照批注阅读器.html
├── 逐段中英文对照全文.md
├── 快速阅读.html
├── 快速阅读.md
├── 全文导读.html
├── 全文导读.md
└── 制作源文件/
    ├── 原文.pdf 或 原文.html
    ├── reader-data.json
    ├── 内容核对.json
    └── 构建脚本及实际使用的图像、样式、脚本
```

交付的 HTML 默认离线可读。仅在用户要求时另做 PDF 或 Word，并使用相应格式技能渲染检查。多篇任务逐篇交付、逐篇记录状态，可生成统一阅读入口，不因其中一篇来源缺失而放弃其他篇。

## 验收与回复

- 按原文目录、正文、附录、图表、脚注和参考文献分别核对数量与覆盖；检查漏译、重复段、错位、ID 冲突，以及关键数字、单位、公式和否定。
- 实际打开 HTML，按参考文件核验批注、备份恢复、导读答题、导航、离线阅读与窄屏布局。区分“内容核对通过”和“浏览器功能已验证”，如实记录尚未执行的检查。
- 检查快速阅读与全文复用内容一致，导读链接指向真实位置，源码不依赖临时目录或另一篇论文。
- 提交前逐句删除只为预防质疑的自我辩护，保留影响结论、范围或证据解读的限定。忠实译文中的原文内容不因此删改。
- 最终简短给出阅读器、快速阅读和可编辑译稿的链接；若有缺项，列出具体章节或材料及其对完成状态的影响。完整范围未完成时不得宣称全文翻译完成。
