# 对照阅读包的制作与验收

本文件补充 SKILL.md 中的阅读器、导读与内容核对要求。两种翻译技能各自包含本文件，可独立使用。

## 原文与译文数据

用结构化数据作为 HTML、Markdown 和快速阅读的共同来源，避免手动维护多个译文版本。推荐的单元示例：

```json
{
  "id": "b0012",
  "section": "1 Introduction",
  "kind": "body",
  "en": "Actual source paragraph.",
  "zh": "对应的完整中文译文。",
  "sourceUrl": "https://example.org/paper#section1",
  "pdfPage": 3,
  "translatorNote": "仅在确有原文疑点时填写。"
}
```

`pdfPage` 仅在真正建立 PDF 页码映射时使用。HTML 只有锚点时保留锚点，界面称“对照单元”。没有可用链接时用来源文件及章节定位，不编造 URL。示例域名不得进入实际交付。

章节标题、表格条目、图注、图中文字、脚注、算法和参考文献可以有独立 kind。图片用本地资源或嵌入数据；表格保留行列对应，不仅保留截图。代码和公式使用能够保持原有结构的渲染方式。

同一译文单元的 ID 跨修改保持稳定。文字重新分段会影响批注偏移，改版时保存旧版及备份，不能让旧笔记悄悄指向另一段文字。

## 可批注离线阅读器

默认包含以下可用功能，不以静态按钮充数：

- 英文在上、中文紧接其下；字体易读，支持字号调整。长公式、代码和表格在自身容器内滚动，窄屏不把整个页面撑宽。
- 章节目录、双语搜索、段落锚点、原文位置入口和继续上次阅读；只有映射了 PDF 页码时提供原文页码跳转。
- 英文和中文均可选字高亮、下划线和写笔记；也可按整个段落记笔记。批注列表支持回跳、编辑、删除。
- 批注自动保存在当前浏览器本地；导出与导入 JSON 备份；导出 Markdown 阅读笔记。Markdown 不充当恢复用备份。
- 每篇论文、版本和阅读模式使用独立文档标识，正文批注与导读答题分开存储。相同阅读包的多个入口如共享批注，使用相同正文单元与显式兼容标识；不同内容不得共用一个固定存储键。
- 导入时检查文档与版本、段落 ID、文字偏移及摘录是否匹配；格式或版本不兼容时给出提示，保留现有笔记。重复 ID 按更新时间合并，导入的笔记与回答使用纯文本处理。
- 离线直接打开 HTML 可阅读及操作；正文和交互不依赖在线 CDN、远程字体或运行中的开发服务器。
- 图可放大；图内无法直接选字时，在旁边提供可选取的图中文字对照。

开始阅读说明只需讲清入口、怎样批注、怎样备份和恢复。说明“保存在当前浏览器，不会自动写回 PDF 或同步到其他设备”；存储失败时给出可见提示和导出办法。

已有可用阅读器时优先复用其模板和构建方法，再修改本篇数据、版本、存储标识与范围说明；不能只更换标题后保留上一论文的页数、作者、摘要或目录。技能本身不依赖某个历史项目的绝对路径。

## 教程导读与答题

以“直观例子 → 机制与术语 → 回原文看证据 → 自测”组织理解路径。问题与提示配对、ID 稳定，开放题给出核对思路，不伪装成唯一标准答案。

HTML 为每题提供回答区，自动保存；提示默认折叠，读者先回答再展开。答题数据支持 JSON 导出／导入与 Markdown 导出，刷新后保留。记录实际涉及的原文位置，导读中的链接不得指向不存在的单元。

## 内容核对记录

在 `制作源文件/内容核对.json` 中记录实际检查结果，建议包含：

- 论文题名、版本、原文来源、制作日期及翻译模式。
- 本次翻译的章节、图表、脚注、附录、参考文献范围；存在与缺失项分别列明。
- 来源单元数、已译单元数、漏译 ID、重复 ID、图表与相关文字的覆盖情况。摘要／序言／总结模式按章节分别记录。
- 内容疑点及会影响理解的限制，明确区分原文问题、材料缺失和提取失败。
- 正文和导读存储标识；执行过的界面验证及其结果。

数字由实际数据统计，不能复制前篇的固定计数。只用“译出数等于单元数”不能证明完整，仍需对照原文目录、节末、表格、图片与附录检查提取遗漏。

## 最小可用验证

先完成内容核对，再对实际生成的 HTML 做以下代表性检查：

1. 打开页面，确认正确题名、章节、英中对照与图表，无加载或脚本错误。
2. 分别在英文和中文中选字，验证高亮、下划线、写笔记、编辑、删除与摘录回跳。
3. 新建一条笔记，刷新；导出 JSON；在隔离的测试上下文导入，检查内容和位置恢复，重复导入不增殖。用另一篇论文的备份确认不会串篇。
4. 填写导读回答并刷新；验证提示折叠、JSON 往返、Markdown 导出以及与正文批注相互独立。
5. 验证目录、搜索、原文位置、阅读位置恢复和字号；检查图形放大与关键导读链接。
6. 检查桌面与窄屏，尤其是长标题、公式、代码、表格和图像；断开网络后检查内容及核心交互。

验证使用测试数据与隔离浏览器上下文，不清除用户真实批注。记录实际执行过的结果；仅有静态代码检查时不能写“浏览器测试通过”。发现问题后修复并重测对应功能。

## 沿用的用户要求

- 2026-09-21 的快速阅读任务要求按第二篇标准制作“摘要、序言、导读”，每篇单独建“序号＋文章标题”文件夹。
- 同日 Model of Models 任务明确要求全文翻译按“一段英文－一段中文”上下对照，并单独提供摘要、序言、导读。
- 2026-10-10 的任务要求将首次阅读顺序中未译论文按第二篇标准完整翻译。实际已交付包包含正文、附录、图表文字、参考文献题名、可批注阅读器和教学导读。
- 2026-11-24 本次要求将方法整理为“论文完整翻译”和“论文简要翻译”两个技能，并将简要翻译范围明确为摘要、序言、总结。因此简要技能保留原有导读，同时增加原文总结／结论翻译。

以上用于说明默认要求的来源；本次具体任务指令始终优先，不将旧论文内容、序号、许可状态或未完成原因套用到新论文。
